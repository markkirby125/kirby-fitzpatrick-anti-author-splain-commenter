The **kirby-fitzpatrick-anti-author-splain-commenter** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Core Patterns

- **Anti Author Splain**: Anti-Author-Splain Filter: ban apologetic fluff ('I tried my best to...', 'obviously this does...'), keeping comments forensic.
- **Practical Application**: Inline code comments, PR discussions, and commit explanations.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
